# Hospital Readmission Risk Pipeline

A complete end-to-end ML pipeline to predict patient readmission risk using real hospital data.

## 🛠️ Tech Stack
- **Python** (Pandas, Scikit-learn, Boto3)
- **PostgreSQL** (Supabase)
- **AWS S3** (Data + Model Storage)
- **Machine Learning** (Random Forest + SMOTE)

## 📊 Dataset
- Source: Kaggle - Diabetes 130-US Hospitals (https://www.kaggle.com/datasets/brandao/diabetes)
- 71,518 patient records
- 47 features

## 🔄 Pipeline Flow

├── RiskPipelineProject.ipynb  # Main notebook
├── data/                      # Stored in AWS S3
